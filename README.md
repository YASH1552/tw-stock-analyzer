# 台股分析工具（TW Equity Terminal）

在自己電腦上執行的台股分析網頁。輸入股票代號或名稱，就會顯示買點評分、趨勢、歷史機率、籌碼與相關新聞。
全部使用免費資料，不需要 API 金鑰，也不會產生費用。

## 功能

- **買點評分（0–100）**：綜合趨勢結構、相似歷史情況的勝率、買點檢查表、風險報酬，權重經過 60 檔股票的逐日回測驗證
- **評分可信度**：顯示這檔股票與多檔合併的歷史回測結果，清楚標示評分的實際效果
- **K 線圖與機率區間**：過去相似情況下，1 週、1 個月、3 個月後八成的價格落點
- **買點檢查表**：趨勢、過熱、支撐、量價、法人、本益比、月營收、融資等 10 項
- **同業比較**：與同產業成交金額最大的股票比較漲跌與評分
- **營收與籌碼**：月營收年增率、三大法人買賣超、融資融券、本益比走勢
- **相關新聞**：近 7 天新聞，附偏多／偏空關鍵字標記與原文連結
- **選股掃描**：依成交金額掃描熱門股並依評分排序

## 安裝與執行（Windows）

1. 安裝 [Python 3.10 以上](https://www.python.org/downloads/)
2. 點兩下 `啟動.bat`

第一次執行會自動在資料夾內建立專屬的 Python 環境（`.venv`）並安裝套件，約需 3～5 分鐘。
之後每次啟動約幾秒鐘，瀏覽器會自動打開 http://localhost:8765 。

手動執行：

```bash
python launch.py
```

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `app.py` | 網頁介面（Streamlit） |
| `analysis.py` | 技術指標、趨勢判斷、買點評分、歷史機率、回測 |
| `data.py` | 抓取資料與本機快取 |
| `screener.py` | 選股掃描與同業比較 |
| `validate.py` | 多檔股票驗證評分：`python validate.py [股票數量]` |
| `launch.py` / `啟動.bat` | 啟動程式，自動建立與修復 Python 環境 |

## 資料來源

- [FinMind](https://finmindtrade.com/)：股價、除權息、三大法人、本益比、月營收、融資融券、加權指數（免費版每小時約 300 次查詢）
- 臺灣證券交易所、證券櫃檯買賣中心 OpenAPI：全市場每日成交資料（選股掃描用）
- Google 新聞 RSS：相關新聞（僅限個人、非商業使用）

資料會快取在 `cache` 資料夾，每個交易日收盤後自動更新。
